# Сборка и установка плагина

Плагин дополнен интеграцией с self-hosted gmodwiki: он подгружает функции, классы,
библиотеки и хуки, задокументированные на custom-вики (например, Trolleybus System),
и даёт для них автодополнение, hover-подсказки и подсказки сигнатур — как для
официального API. Данные берутся с эндпоинта `/gluadump.json` вики и автоматически
обновляются при изменении страниц.

## Требования

- Node.js 18+ (проверено на 22)
- Git (зависимость `gluaparse` ставится из git-репозитория)
- VS Code для установки готового `.vsix`

## Сборка

Из корня проекта:

```bash
npm ci
npx webpack --mode production
npx vsce package
```

Результат — файл `vscode-glua-enhanced-<версия>.vsix` в корне проекта.

Для разработки: `npm run webpack-dev` (пересборка при изменениях), запуск — F5 в
VS Code (конфигурация Extension Host из `.vscode/launch.json`).

## Установка

Через терминал:

```bash
code --install-extension vscode-glua-enhanced-2.6.0.vsix
```

Либо в VS Code: Extensions → меню `...` → **Install from VSIX...** → выбрать файл.
Если ранее стояла версия из маркетплейса — удалите её, чтобы не конфликтовали.

## Настройка интеграции с вики

Settings → расширение **GLua Enhanced** (или `settings.json`):

| Настройка | По умолчанию | Описание |
|---|---|---|
| `glua-enhanced.customWiki.url` | `http://127.0.0.1:4321` | Базовый URL вашей вики. Пустая строка — интеграция выключена |
| `glua-enhanced.customWiki.pollSeconds` | `60` | Как часто проверять вики на обновления документации (секунды, 0 — только при старте) |

Работает это так: при активации плагин применяет закешированную копию данных
(мгновенно, офлайн), затем скачивает `<url>/gluadump.json` и каждые `pollSeconds`
секунд опрашивает `<url>/gluadump.json?check=1` (лёгкий запрос, только версия).
Как только на вики изменилась/добавилась страница — версия меняется, плагин
скачивает свежие данные и пересобирает автодополнение. Перезапуск VS Code не нужен.

В hover-подсказках у custom-функций ссылка **Wiki** ведёт на страницу вашей вики,
**Edit** — прямо в её редактор.

## Что попадает в автодополнение с вики

- `Trolleybus_System.*` и вложенные библиотеки (`.ContactNetwork`, `.Routes`,
  `.NetworkSystem`, `.DeviceInputModule`) — как обычные библиотеки
- Методы классов (`Trolleybus:*`, системы `TISU:*`, `Engine:*`, ..., entity
  `trolleybus_stop:*` и т.д.) — в автодополнении после `:`
- Хуки `TrolleybusSystem_*` — в `hook.Add(...)` (семейство TROLLEYBUS)
- Глобальные функции — в общем списке

Страницы вики без `<function>`-разметки (обзорные) в дамп не попадают, но дают
описания классам/библиотекам.
